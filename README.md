# Replyboard

Public leaderboard ranking YouTube creators by how responsive they are in their own comment sections.

## Setup

Requires **Node 24** (see [`.nvmrc`](.nvmrc)) and **pnpm 12** (`corepack enable` or `npm exec pnpm@12.18.0 -- install`).
